# Data Review

**Status:** Not started.
**Date:** 2026-09-13

The project cannot train until a person reviews twenty generated conversations.

## Required Checks

- Every reply sounds like the same character.
- No reply offers help or asks whether more help is needed.
- No assistant reply exceeds 60 words.
- The hard cases stay in character.
- No line copies anime, manga, or subtitle text.
- Every reply stays wholesome and non-explicit.
